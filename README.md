番茄钟.exe
一：番茄钟产品设计
1.选型：确定开发技术栈（桌面端 Python/Qt、前端网页版、小程序版等）
2.搜集参考文献：番茄工作法原版理论、时间管理类文献不少于 40 篇
3.基于技术选型 + 参考文献，生成论文初稿（产品需求、设计思路、实现原理）
4.完善初稿框架：绪论、需求分析、系统设计、代码实现、测试、总结章节
5.AI 润色优化全文格式、语句、学术规范
6.审核定稿，形成终版论文文档
二：画图（番茄钟界面 + 配图）
1.搜集优秀番茄钟软件的界面原型、系统架构配图参考
2.根据论文内容生成 AI 绘图提示词（主界面、倒计时页面、统计看板、设置页）
3.参考优质配图风格，多次对话调用 AI 生成整套图片素材
4.整理：程序架构图、UI 效果图、功能流程图、数据统计图
三：作者信息、期刊 / 发布公众号信息配置
1.维护信息表格：作者姓名、开发单位、联系方式、邮箱、项目简介
2.录入投稿 / 发布主体信息（期刊编号、公众号主体、小程序主体资料）
3.打包全部资料：论文 + 图片 + 源码说明，形成投稿压缩包 zip
四：投公众号、自媒体 / 应用渠道上架
1.选择发布载体：微信公众号、小红书、知乎、应用商店、小程序平台
2.账号注册 / 登录：AI 辅助自动填写邮箱验证码、身份核验信息
3.AI 驱动网页端操作：上传图文、填写上架介绍、设置封面图
4.AI 智能巡检：检测文案违规、图片适配、排版问题，修正发布素材
