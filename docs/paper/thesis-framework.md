# 番茄工作法计时系统的设计与实现

## 论文框架

---

## 摘要

> 本文针对现代人普遍面临的工作效率低下、注意力分散等问题，
> 基于Francesco Cirillo提出的番茄工作法理论，
> 设计并实现了一款跨平台桌面番茄钟计时应用。
> 系统采用PyQt6框架，以有限状态机为核心驱动计时逻辑，
> 结合任务管理、数据统计和个性化设置等辅助功能，
> 形成了一套完整的个人效率管理工具。
> 实验结果表明，该工具能有效提升用户的专注时长和任务完成效率。

**关键词**: 番茄工作法；时间管理；PyQt6；有限状态机；专注力

## 第二章 需求分析

### 2.1 用户群体分析
- 目标用户画像（学生、程序员、创意工作者）
- 用户痛点调研
- 典型使用场景

### 2.2 功能需求
- **核心功能**:
  - 番茄计时器（工作25min/短休息5min/长休息15min）
  - 状态管理（开始/暂停/停止）
  - 通知提醒
- **辅助功能**:
  - 任务管理
  - 数据统计
  - 系统托盘
- **扩展功能**:
  - 自定义设置
  - 主题切换
  - 多语言支持

### 2.3 非功能需求
- 性能指标：内存占用 < 100MB，CPU 占用 < 5%
- 可用性：启动时间 < 2s，操作响应 < 100ms
- 可维护性：模块化设计，易扩展
- 跨平台：Windows / macOS / Linux

### 2.4 需求优先级矩阵

| 功能 | 优先级 | 复杂度 | 依赖 |
|:---|:---:|:---:|:---:|
| 基本计时 | P0 | 低 | 无 |
| 通知提醒 | P0 | 低 | OS API |
| 数据统计 | P1 | 中 | 文件系统 |
| 任务管理 | P1 | 中 | 无 |
| 系统托盘 | P1 | 低 | Qt API |
| 自定义时长 | P2 | 低 | 配置文件 |
| 主题/国际化 | P3 | 中 | 资源文件 |
